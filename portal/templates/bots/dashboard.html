Exness (MT5 — live trading) {% if c %}{{ c.status }}{% endif %}

After you unlock the bot, connect Exness through MetaTrader 5. A small MT5 bridge runs next to your MT5 terminal (Windows PC or Windows VPS) and receives orders from our server. Your MT5 password never leaves your machine. Native MT4 bridge is not used — log into the same Exness account in MT5.

  1. Download the package → folder mt5_bridge. Install MetaTrader 5 from Exness and Python 3.11.
  2. Run pip install -r requirements.txt, copy config.example.json to config.json, fill your MT5 login, password, server (e.g. Exness-MT5Real) and invent a long token.
  3. Run python bridge.py. Make port 5055 reachable from the internet (VPS public IP, router port-forward, or a free tunnel like Cloudflare Tunnel) - the guide in the folder shows each option.
  4. Paste the bridge URL and the same token here, choose "Exness" as broker.
