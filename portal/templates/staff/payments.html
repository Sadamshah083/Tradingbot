Setup (once)

  1. Create a Stripe account at stripe.com and copy the Secret key (Developers ←’ API keys). Put it in the server's portal/.env as STRIPE_SECRET_KEY=sk_live_... (use sk_test_... first to test with card 4242 4242 4242 4242).
  2. Developers ←’ Webhooks ←’ Add endpoint: URL {{ webhook_url }}, events checkout.session.completed, checkout.session.async_payment_succeeded, checkout.session.async_payment_failed, checkout.session.expired, charge.refunded. Copy the signing secret into STRIPE_WEBHOOK_SECRET=whsec_....
  3. Restart the portal service. The "Pay by card" button appears on checkout automatically.
